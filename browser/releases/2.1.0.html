Release notes · Version 2.1.0 · September 14, 2026

A refreshed Plex.
Built for your desktop.

Version 2.1.0 brings the updated Plex interface to Windows, macOS and Linux, with more useful bookmarks, flexible tabs and clearer controls.

Reported performance

Reported speed gains.

Up to76%faster than Chrome
Up to163%faster than Firefox
Up to89%faster than Edge

Peak comparison figures reported by Plexium, not independently verified. Results vary by device, workload and browser settings. The comparison methodology, hardware and browser versions have not been published; these figures are not a guarantee for every platform or browsing task.

Cleaner controls and themes

  • Warm Plex styling with glass-like highlights, clearer buttons and restrained motion.
  • Light, Dark, Incognito, PlexUI Light and PlexUI Dark appearances.
  • Incognito appearance can be selected independently of private browsing.
  • Toolbar customization and reset controls for accent, glow and glass tint.

Tabs and window layout

  • Tabs sit at the top of the window and shrink as more are opened.
  • A tab-search panel helps locate an open page.
  • Updated sizing for compact layouts and resized windows.
  • Native Windows caption controls remain alongside the tab strip.

Bookmark folders

  • A smaller bookmark library with search and folder filtering.
  • Folder buttons on the bookmarks bar reveal their contents on hover.
  • An All menu provides another route into larger bookmark collections.
  • Duplicate-bookmark prevention and editable bookmark titles, addresses and folders.

Search and navigation

  • Suggestions appear beneath the address bar.
  • Google and DuckDuckGo suggestions follow the selected provider.
  • History-based suggestions help revisit YouTube, Reddit and GitHub pages.
  • Back navigation can return to the start page; submitting an AI shortcut closes its panel.

Privacy and page actions

  • One visible secure-DNS ad-blocking control using AdGuard DNS.
  • Private browsing stays separate from choosing the Incognito theme.
  • Contextual page actions include copying links and saving images.
  • Release packages include no developer history, downloads, cookies or profiles. Existing users keep their local data.

Three desktop platforms

  • Windows x64 uses a C#/.NET host with WebView2, tuned for Windows performance.
  • macOS uses Chromium, with separate Apple Silicon and Intel downloads.
  • Linux uses Chromium, packaged as a Debian/Ubuntu amd64 installer.
  • All downloads include published SHA-256 checksums.

Before installing

All platform packages built successfully, and the Linux startup check passed. Full interactive macOS testing and cross-platform performance comparisons remain unverified. Windows requires Microsoft Edge WebView2 Runtime. Installers lack publisher certificates; macOS builds are not notarized and may require approval in Privacy & Security.

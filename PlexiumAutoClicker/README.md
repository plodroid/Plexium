# Plexium Auto Clicker

A Windows auto clicker written entirely in C# / WinForms.

Features:
- Adjustable hours/minutes/seconds/milliseconds interval
- Left, right, middle click or keyboard-key spam mode
- Changeable global toggle hotkey (default H)
- Changeable spam key (default P)
- Global input macro recorder (keyboard + mouse movement/clicks)
- Playback speed from 0.25x to 3.00x
- Plexium-inspired warm dark UI

Build target: Windows x64, .NET 8, self-contained single-file publish.

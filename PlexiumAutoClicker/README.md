# Plexium Auto Clicker

A simple Windows auto clicker written in C# / WinForms.

Features:
- Simple classic UI with Dark and Light themes
- Hours, minutes, seconds, and milliseconds interval
- Random interval jitter
- Left, right, middle, single, and double click
- Keyboard key spam mode with changeable key
- Changeable global toggle hotkey
- Repeat until stopped or repeat a set number of times
- Optional fixed cursor position and position picker
- Optional delayed start
- Mouse + keyboard macro recorder
- Macro playback from 0.25x to 4.00x and optional loops
- Ignores its own injected input in global hooks

Build target: Windows x64, .NET 8, self-contained single-file executable.

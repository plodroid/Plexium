Game 01

BoxPvP

BoxPvP is the main progression PvP arena. Players enter the box, mine the allowed resources, build up value, buy upgrades and fight around the custom map.

Core loop

  • Enter through the Plexium lobby and head to the BoxPvP world.
  • Mine resources inside the configured arena regions.
  • Use the server shops and custom NPC areas to turn progression into stronger tools and utility.
  • PvP is centered around the box while protected travel/spawn areas stay controlled through WorldGuard.
The map uses region-specific block rules: the arena can allow selected blocks such as prismarine, dark prismarine, raw gold blocks, terracotta, concrete and glazed terracotta without removing protections everywhere else.
BoxPvP systems

Shop, TNT & custom items

The BoxPvP shop has custom purchase behavior instead of relying on vanilla item dropping.

TNT purchasesTNT purchases can fill available inventory space directly. When the inventory is full, TNT overflow does not spill onto the floor, avoiding item-drop lag.
TNT restrictionsTNT use is tied to the intended mining/progression rules. WorldGuard placement restrictions are not supposed to make purchased TNT unusable for normal players.
Diamond-block pricingThe TNT shop was moved to diamond-block pricing, with the updated shop config controlling the current cost for each TNT option.
Mr Krabs areaThe red stained-glass restriction is limited to the intended /pg spawn area, so it does not block players from reaching the Mr Krabs location.
BoxPvP systems

Codes, spawn & protections

  • /codes opens the code flow and clearly shows where the player should type a code.
  • An invalid code should return the player cleanly instead of leaving them stuck inside the sign/input state.
  • Events were removed from the custom shop flow.
  • Spawn barriers and red stained glass are scoped to the spawn system rather than globally blocking unrelated NPC locations.
  • WorldGuard still controls ordinary placing/breaking, while custom plugin logic handles exceptions required by the game.

The network also uses the wider server stack for permissions, NPCs, tab display, version compatibility, world management and protection.

Game 02 · JAR 1.0.0

Island Wars

Island Wars is a void-only knockback minigame. The plugin describes itself as a “void-only knockback island minigame with money-per-damage swords.” Every configured sword has its own price, knockback, passive proc and right-click special.

How a fight works

  • You start with the free Tier 1 Rookie Tapblade when the default-sword join setting is enabled.
  • Damage dealt with configured swords earns money. The shipped configuration pays $1 per damage.
  • Recent attackers can receive a $10 void-kill bonus when a victim falls into the void within the configured 15-second credit window.
  • Plugin swords do not lose durability, and the game is configured to keep inventory on void death.
  • Each sword has normal knockback plus a chance-based passive ability. Right-clicking uses that sword’s separate active ability when it is off cooldown.
Island Wars

Economy, voids & progression

$1 per damageThe default config uses money-per-damage: 1.
+$10 void killVoid bonus credit lasts 15,000 ms after the qualifying hit.
45 tiersPrices rise from the free Rookie Tapblade to the $6,305,000 Titan Mace.
Persistent unlocksThe plugin tracks money, void deaths and unlocked swords per player.

A player’s sword tooltip exposes combat information such as ability text, bonus damage, right-click special and void bonus details. The plugin also tracks void falls and uses a “Void King” style stat presentation.

Island Wars

Shop & controls

Use /shop to open the sword shop. The GUI supports cycling filters, equipping already-unlocked swords and unlocking swords you can afford. You can also use /shop <word> for text search.

Shop entriesShop entries are used to unlock or equip swords depending on ownership.
Right-click in combatUses the equipped sword’s active ability. Active abilities have their own cooldown and visual/sound feedback.
Passive procHitting with a configured sword can trigger its chance-based passive ability.
Search/shop <word> searches sword names and the shop UI includes filters.

Ability families found in the JAR

Examples include dash, slime trap, pull field, quake, boomerang pulse, reverse field, clone, meteor strike, phase shift, time freeze, counter stance, domain expansion, fish save, swap strike, octopus blind and tornado-style actives. Passives include extra shove, sky launch, slow/pop, area shockwave, speed boosts, disorient effects, levitation and bonus-money effects.
